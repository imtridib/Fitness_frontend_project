# Fitness Website — Responsive Front-End Project

A static fitness website concept implemented with HTML and CSS, accompanied by design reference files for desktop, tablet, and mobile layouts.

## Project structure

- `index.html` — website markup.
- `styles/style.css` — page styling.
- `images/` — trainer, exercise, and page imagery.
- `All Design Files/` — Figma source and exported design references.

## Run locally

Open `index.html` in a browser or use VS Code Live Server. Keep the `images/` and `styles/` folders beside the HTML file as committed.

This is a static front-end practice project. The repository includes responsive design references and does not currently document a backend or user-account system.
